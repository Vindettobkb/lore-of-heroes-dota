# Хроники Древних

Фанатский архив героев Dota 2: лор, способности и визуальная атмосфера мира Древних.

## Что есть сейчас

- Переключение стиля между 3 цветовыми темами: **Лес**, **Пепел**, **Бездна**.
- Лор героев оформлен и структурирован, добавлены изображения и иконки.
- Добавлен раздел **предметов Dota 2**: сетка арсенала, поиск, фильтры и модальное окно с описанием и лором.
- Контент собран в удобном формате для чтения.
